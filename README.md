# ASMA: AHIBS Management

Buatkan aplikasi web bernama "ASMA" (Aplikasi Sistem Manajemen AHIBS) untuk

SMPIT Putra Al-Hanif, sebuah SMP berbasis pesantren (Islamic boarding school)

dengan 100–300 santri putra.

Gunakan React + TypeScript + Tailwind CSS. Gunakan Supabase sebagai backend

(database, autentikasi, dan storage) — aktifkan integrasi Supabase native

Lovable.

Untuk tahap ini, buat dulu:

1. Halaman Login sederhana (email + password) yang terhubung ke Supabase Auth.

2. Layout dasar aplikasi setelah login: sidebar kiri (di desktop) dan bottom

   tab bar (di mobile), dengan area konten di kanan/atas.

3. Satu halaman placeholder "Dashboard" yang tampil kosong dulu (akan diisi

   di tahap berikutnya).

Desain: gaya modern-islami, warna dasar biru tua (#1E2A8A) dan aksen oranye

keemasan (#F28C18), rounded corner lembut, tipografi bersih dan mudah dibaca.

Tampilkan logo teks "ASMA" dengan badge kecil "AHIBS" di pojok kiri atas.

Jangan buat data dummy dulu, jangan buat modul lain dulu — cukup fondasi ini.
